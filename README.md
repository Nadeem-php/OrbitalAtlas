# OrbitalAtlas
**Orbital Atlas** is an interactive astronomical and space-knowledge website created by **Nadeem Ali**, designed to make the fascinating world of space easier, more engaging, and more accessible to explore.

The platform brings together knowledge about the **Universe, planets, stars, galaxies, satellites, space missions, celestial objects, and astronomical phenomena** in an interactive digital environment. The goal of Orbital Atlas is to help users explore space not just by reading information, but by visually discovering and understanding the objects and events that make up our Universe.

Orbital Atlas is a personal project developed by Nadeem Ali through **vibe coding**, with the assistance of **Manus.im**, combining creativity, curiosity, modern web technologies, and AI-assisted development. The project represents an exploration of how AI and modern software development tools can be used to transform an idea into an interactive educational experience.

Rather than being limited to a traditional encyclopedia-style website, Orbital Atlas is intended to evolve into an **interactive space exploration platform**, where users can discover astronomical objects, explore their locations, learn about space missions, visualize information, and gain a deeper understanding of the Universe.
